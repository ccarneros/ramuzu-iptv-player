## Ramuzu IPTV Player 5.0

First release of Ramuzu IPTV Player for Windows 10 and 11.

### Download

- **`RamuzuIPTVPlayer-5.0-windows-x64.zip`**: portable version. Unzip it anywhere and run `Ramuzu IPTV Player.exe`.

You don't need Python. To play streams, install [VLC](https://www.videolan.org/vlc/); the app finds it automatically.

> The app is not code-signed. If Windows SmartScreen shows "Windows protected your PC", click **More info → Run anyway**.

### What's included

- Live TV, Movies and Series from Xtream Codes or M3U (get.php) accounts
- Favorites tab: right-click or press Ctrl+D to star a channel, movie or series
- TV guide with the programme on air next to each channel
- Poster, synopsis and details when you hover over movies and series
- Saved accounts that connect automatically at startup, with passwords stored in Windows Credential Manager
- Light, dark or system theme, and adjustable text size

Ramuzu IPTV Player is only a player and does not provide any content.
